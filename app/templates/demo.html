Behind the scenes

How a real reply actually ships

The two tools above preview the drafting and triage agents live. What they can't show is the always-on system that runs for real prospects — shown here, not simulated:

Poller checks Twilio — no webhook. A script asks Twilio's API "anything new?" on an interval, deliberately avoiding a webhook so it never conflicts with other apps sharing the number. app/poll_inbound.py
Triage agent classifies it — the same one you just used above — interested, question, not interested, opt-out, or hot lead, with a confidence score. app/agents/triage_agent.py
Draft agent suggests a reply — the same agent powering the chat tool above, but for a real prospect. app/agents/draft_reply_agent.py
A human reviews before it sends — a push notification goes out, and every real reply is approved, edited, or skipped by a person before it reaches anyone. app/review_pending.py
